# House Price Prediction: From Linear Models to Gradient Boosting

End-to-end machine learning project using the Kaggle House Prices dataset. The project covers exploratory data analysis, missing-value investigation, preprocessing, linear and regularised regression, ensemble models, cross-validation, error analysis, and Kaggle submission.

## Current result

- Best model: Tuned Gradient Boosting
- Validation RMSE: 0.1363
- Best 5-fold CV RMSE: 0.1283
- Kaggle public leaderboard score: 0.13057
